- Subagents are installed from Pi's shipped `examples/extensions/subagent` into `extensions/subagent`, with user agents in `agents/` and workflows in `prompts/`. The active roster is intentionally small: `scout` uses `google-vertex/gemini-3.8-flash:high`, `worker-lite` uses direct `openai-codex/gpt-5.6-luna:high`, `worker` uses direct `openai-codex/gpt-5.6-terra` with per-invocation `effort=low/medium/high` (default `high`), and `browser` uses `openai-codex/gpt-5.6-luna`. Retired agents and the old prompt-only effort profiles live under `archive/agents/` and are not discovered. Planning and review are handled by the main agent.
- DeepSeek reasoning effort needs no config in `models.json`. `detectCompat()` in `pi-ai/api/openai-completions.js` already sets `supportsReasoningEffort: true` for deepseek (only grok/zai/moonshot/together/cloudflare-gateway/nvidia/ant-ling are excluded), and the shipped model store defines `thinkingLevelMap` with `high: "high"` and `max: "max"` plus `thinkingFormat: "deepseek"`. A redundant `modelOverrides.deepseek-v4-pro.compat.supportsReasoningEffort` entry was removed. Verified against a local capture proxy: `deepseek/deepseek-v4-flash:high` sends `reasoning_effort: "high"`, and both `deepseek-v4-flash:max` and `deepseek-v4-pro:max` send `reasoning_effort: "max"` with `thinking: {"type": "enabled"}`. With the `models.json` override mapping `low` → `"low"`, the effective DeepSeek levels are `low`/`high`/`max`; `medium` clamps up to `high` and `xhigh` clamps up to `max`.
- Compaction is routed through `extensions/compaction-model.ts` to `openai-codex/gpt-5.6-luna`, while retaining Pi's built-in summary format, split-turn handling, file tracking, custom `/compact` instructions, and current thinking level. `/compact-current [instructions]` performs a one-off compaction with the active model. Each completed compaction reports its model; Luna compactions also persist `details.compactionModel` in the session entry. If Luna or its auth is unavailable, the handler falls back to Pi's active-model compaction. DeepSeek Pro remains an enabled model; it was not previously a dedicated compaction model.
- Pi/OpenAI Codex Fast Mode is implemented in `extensions/service-tier-priority.ts`: use `/fast [on|off|toggle]` to add `service_tier: "priority"` to real GPT-5.4, GPT-5.5, and GPT-5.6 family requests without fake priority model aliases.
- Doubled Enter/Tab/Backspace input in Pi was caused by Alacritty 0.13.2's Kitty keyboard handling. `keybytes --pi-query` showed plain duplicate bytes: Enter `0x0d 0x0d`, Backspace `0x7f 0x7f`, Tab `0x09 0x09`. Updating Alacritty to 0.17.0 fixed the raw input, so the old `PI_TUI_KITTY_KEYBOARD_FLAGS=0` shell workaround and `extensions/alacritty-key-dedupe.ts` were removed.
